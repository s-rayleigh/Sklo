# Sklo

A lightweight UI framework for Unity that simplifies composing screens out of reusable layers and switching between them.

> [!WARNING]
> Sklo is a work in progress. The API is unstable and may change significantly between versions.

Requires Unity 2022.3 or newer.

## Assemblies

| Assembly | Contents |
|---|---|
| `Rayleigh.Sklo` | Core: screens, layers, layer views, the synchronous screen manager. |
| `Rayleigh.Sklo.Async.Tasks` | Async variants based on `Task`. |
| `Rayleigh.Sklo.Async.UniTasks` | Async variants based on [UniTask](https://github.com/Cysharp/UniTask). Compiled only when the `com.cysharp.unitask` package is installed. |
